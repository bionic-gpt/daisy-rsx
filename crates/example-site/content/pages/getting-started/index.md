# Getting Started

This starter page gives your site a second content type beyond the homepage and blog.

## What's Included

- A homepage rendered from Rust
- A blog index with one starter article
- A static markdown page at `/getting-started`
- Shared site assets and custom JavaScript hooks
- A Cloudflare build script

## Next Steps

Update the copy, replace the logo and favicon, and add your own pages under `content/pages/`.
